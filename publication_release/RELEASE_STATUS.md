## Verification and study limits

Use [REPRODUCIBILITY.md](../REPRODUCIBILITY.md) to clone `v1.0.0-paper` and verify its exact manifest. Because that manifest includes documentation, full snapshot verification and its portable test must run from the frozen checkout. The existing branch workflow checks its current checkout against that same frozen manifest, so later documentation revisions cause an expected hash mismatch. This docs-only cleanup preserves the workflow, tests and frozen seals; any workflow policy change requires separate review before merging.

Public aggregate verification supports table curation, figure drawing, source-string/rounding checks and saved statistical arithmetic. It does not establish complete raw-data-to-paper reanalysis. The four cohorts/endpoints remain separate; Hospital130 concerns 30-day readmission. Evaluation is retrospective and internal; external/prospective validity and clinical benefit are not established. Dynamic switching did not demonstrate consistent Holm-corrected superiority; availability abstention differs from confidence rejection, and SHAP associations are not causal.

Historical training replay remains **BLOCKED**, historical timing-component reconstruction **PARTIAL**, and A4 computational-cost **REPORTING COMPLETE**. Raw records, individual predictions, fitted objects, private splits and bootstrap arrays are not redistributed. See [PUBLIC_RELEASE_LIMITATIONS.md](PUBLIC_RELEASE_LIMITATIONS.md).
